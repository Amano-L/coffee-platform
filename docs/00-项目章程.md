## 1. 项目背景
本项目为个人学习型作品集，旨在通过构建一个真实的“咖啡电商 + 订阅制”业务系统，深度掌握现代 Java 后端技术栈及企业级开发流程。项目以咖啡为业务外壳，覆盖鉴权、CRUD、事务、状态机、并发库存、缓存、消息队列、定时任务、支付回调、后台管理等 Spring 后端核心能力。

## 2. 项目目标

### 2.1 业务目标
- 实现从用户浏览、下单、支付到周期性订阅配送的完整闭环。
- 支持消费者端与管理后台端双角色操作。
- 具备可演示、可讲述、可扩展的业务场景。

### 2.2 技术目标
- 掌握 Java 21 + Spring Boot 3.x + MyBatis-Plus + MySQL 8.x + Redis + RabbitMQ 的整合应用。
- 掌握模块化单体架构设计，理解模块边界与依赖管理。
- 掌握企业级工程规范：统一响应、全局异常、JWT 鉴权、幂等处理、逻辑删除、乐观锁。

### 2.3 工程目标
- 形成一套规范的需求、架构、数据库、API 文档，作为开发与验收的唯一基准。
- 配合 AI 辅助完成 Vue3 前端开发，形成可维护的前后端分离项目。
- 建立 Git 分支规范、提交规范、代码评审清单，养成企业级开发习惯。

## 3. 核心角色

| 角色              | 说明       | 主要职责                                    |
| ----------------- | ---------- | ------------------------------------------- |
| 消费者（C端）     | 普通用户   | 浏览商品、下单、支付、管理订阅、查看订单    |
| 运营管理员（B端） | 后台管理员 | 管理商品、SKU、库存、订单、订阅计划、优惠券 |
| 系统（System）    | 后台任务   | 定时任务、支付回调、消息消费者、库存释放    |

## 4. 成功标准

- 后端接口完整，具备统一响应、全局异常、JWT 鉴权、幂等处理。
- 核心链路（下单-支付-库存扣减-订阅生成）跑通，并通过并发测试（100 并发不超卖）。
- 前端具备基本交互，不报错，能完整演示业务流程。
- 代码结构清晰，符合企业级分层规范。
- 所有文档与代码同步，形成可追溯的工程资产。

## 5. 边界与约束

### 5.1 明确不做
- 微服务架构、分库分表、多租户 SaaS。
- 真实支付对接、真实物流对接。
- Elasticsearch 搜索、推荐算法。
- 复杂营销引擎、多门店管理。

### 5.2 技术约束

| 类别           | 选型                                    | 说明                                                         |
| -------------- | --------------------------------------- | ------------------------------------------------------------ |
| 语言           | Java 21                                 | LTS 版本                                                     |
| 框架           | Spring Boot 3.x                         | 最新稳定版                                                   |
| ORM            | MyBatis-Plus                            | 国内就业友好                                                 |
| 数据库         | MySQL 8.x                               | 主流关系型数据库                                             |
| 缓存           | Redis                                   | 缓存、Token、分布式锁                                        |
| 消息队列       | RabbitMQ                                | 订单超时、通知、订阅任务                                     |
| 前端           | Vue3 + Vite + TypeScript + Element Plus | AI 辅助生成                                                  |
| 接口文档       | Springdoc OpenAPI / Knife4j             | 自动生成                                                     |
| 数据库版本管理 | Flyway                                  | SQL 版本化                                                   |
| 部署           | Docker Compose                          | 本地一键启动                                                 |
| 仓库结构       | 单仓库多工程                            | 根目录 `coffee-platform/`，内含 `backend/`、`frontend/`、`docs/`、`deploy/`、`scripts/` |

## 6. 术语表

| 术语     | 说明                                          |
| -------- | --------------------------------------------- |
| SKU      | 库存量单位，如 250g 整豆、500g 研磨           |
| 订阅     | 用户按周期（周/月）自动获得咖啡配送的服务     |
| 预占库存 | 下单时冻结库存，支付成功后真实扣减            |
| 幂等     | 同一请求多次执行结果一致，防止重复扣款/扣库存 |
| 状态机   | 订单/订阅在有限状态间按规则流转               |
| 逻辑删除 | 通过 `deleted` 字段标记删除，数据不物理删除   |
